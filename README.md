# Zoho Decks

Static HTML decks with a landing page (`index.html`). No build step.

## Deploy
1. Push this repo to GitHub.
2. In Vercel: Add New > Project > import the repo.
3. Framework Preset: **Other**. Leave build command and output directory empty. Deploy.

## Add a deck
Drop the new `.html` file in the root (it references `logos/` and `fonts/`), then add a card block in `index.html`.
